DENGE - Import du logo (Windows)
================================

1. Telechargez ce dossier (ou juste import-logo.py + import-logo.bat).
2. Enregistrez votre image generee par Qwen (mon-logo.png ou .jpg)
   DANS LE MEME DOSSIER que import-logo.bat.
3. Double-cliquez sur import-logo.bat.

Le script cree automatiquement les 6 fichiers dans le sous-dossier public/ :
  logo.png, icon-192.png, icon-512.png, icon-maskable-512.png,
  apple-touch-icon.png, favicon.png

4. Recopiez ces 6 fichiers dans charge-pro/public/ de votre projet,
   puis lancez : npm run build

PRE-REQUIS : Python (https://python.org, cochez "Add Python to PATH")
             et Pillow :  pip install pillow

Alternative sans rien installer : envoyez-moi l'image dans le chat,
je lance l'import a votre place.
